📐 جبر خطی: زبان توصیف فضا و حالت

معادلات فضای حالت، ستون فقرات مدل‌سازی مدرن سیستم‌های دینامیکی است.

$$\dot{\mathbf{x}} = A\mathbf{x} + B\mathbf{u}, \quad \mathbf{y} = C\mathbf{x} + D\mathbf{u}$$ معادلات فضای حالت — پایه مدل‌سازی
$$\mathbf{y} = \mathbf{W}\mathbf{x} + \mathbf{b}$$ نورون مصنوعی — همان ساختار جبری

🎯 در مکانیک

$\mathbf{x}$ بردار حالت (موقعیت، سرعت)، $A$ ماتریس سیستم

🧠 در AI

$\mathbf{x}$ بردار ویژگی، $\mathbf{W}$ وزن‌های شبکه

🎯 مقادیر ویژه — مدهای پنهان

مقادیر ویژه جهت‌های طبیعی سیستم را نشان می‌دهند — در مکانیک و AI یکسان است.

$$A\mathbf{v} = \lambda \mathbf{v}$$ معادله مقدار ویژه — $A$ ماتریس، $\lambda$ مقدار ویژه، $\mathbf{v}$ بردار ویژه

📉 گرادیان — منطق تغییرات

مفهوم فیزیکی: جهت بیشترین تغییرات در میدان‌های دما یا فشار. در AI: جهت بهینه‌سازی برای کاهش خطا.

$$\nabla f = \left[\frac{\partial f}{\partial x_1}, \dots, \frac{\partial f}{\partial x_n}\right]$$ گرادیان — بردار مشتقات جزئی

🌡 در فیزیک

جهت بیشترین تغییرات دما، فشار، پتانسیل

🧠 در AI (Backprop)

جهت به‌روزرسانی وزن‌ها برای کاهش Loss

📊 تخمین پارامتر با داده واقعی

هدف: کمینه‌کردن مجموع مربعات خطا (MSE) بین پاسخ واقعی و پیش‌بینی.

$$MSE = \frac{1}{n}\sum_{i=1}^n (x_{true,i} - x_{model,i}(c,k))^2$$ تابع هزینه برای تخمین پارامتر
$$c_{t+1} = c_t - \eta \frac{\partial MSE}{\partial c}, \quad k_{t+1} = k_t - \eta \frac{\partial MSE}{\partial k}$$ به‌روزرسانی پارامترها با Gradient Descent

🎯 هدف

یافتن c و k بهینه که مدل را با داده واقعی سازگار کند

🔁 فرایند

تکرار به‌روزرسانی تا رسیدن به کمینه خطا

کدنویسی

💻 تخمین پارامتر — MATLAB و Python

% تخمین c و k با fminsearch
t = 0:0.01:10;
x_true = 1 .* exp(-0.5*t) .* cos(3*t);  % داده واقعی

% تابع هزینه
cost = @(p) sum((x_true - 1.*exp(-p(1)*t).*cos(p(2)*t)).^2);

% بهینه‌سازی
p0 = [0.1, 1];
p_opt = fminsearch(cost, p0);

fprintf('c = %.3f, k = %.3f\n', p_opt(1), p_opt(2));
import numpy as np
from scipy.optimize import minimize
import matplotlib.pyplot as plt

t = np.linspace(0, 10, 1000)
x_true = 1 * np.exp(-0.5*t) * np.cos(3*t)  # داده

def cost(p):
    c, k = p
    x_model = 1 * np.exp(-c*t) * np.cos(k*t)
    return np.sum((x_true - x_model)**2)

res = minimize(cost, [0.1, 1.0], method='Nelder-Mead')
print(f"c = {res.x[0]:.3f}, k = {res.x[1]:.3f}")

plt.plot(t, x_true, 'b-', label='واقعی')
plt.plot(t, 1*np.exp(-res.x[0]*t)*np.cos(res.x[1]*t), 'r--', label='تخمین')
plt.legend(); plt.show()
