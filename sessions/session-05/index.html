مفهوم

📈 رگرسیون خطی — Linear Regression

ساده‌ترین مدل: یک خط مستقیم که داده‌ها را تقریب می‌زند.

$$\hat{y} = w_0 + w_1 x_1 + w_2 x_2 + \dots + w_n x_n = \mathbf{w}^T \mathbf{x} + b$$ مدل رگرسیون خطی چندمتغیره

🎯 هدف

یافتن پارامترهای $\mathbf{w}$ و $b$ که خطا را کمینه کند

📐 تابع خطا

MSE — میانگین مربع خطاها

حل تحلیلی

🧮 Normal Equation

حل مستقیم بدون نیاز به تکرار.

$$\mathbf{w} = (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{X}^T \mathbf{y}$$ معادله نرمال — حل دقیق رگرسیون خطی

✅ مزایا

دقیق، بدون تنظیم نرخ یادگیری

❌ معایب

برای داده‌های بزرگ ($n > 10^4$) کند و پرهزینه

⛰️ Gradient Descent

حرکت در جهت خلاف گرادیان برای یافتن کمینه تابع هزینه.

$$\theta_{t+1} = \theta_t - \eta \nabla_\theta L(\theta_t)$$ به‌روزرسانی پارامترها در جهت کاهش خطا

🎚 نرخ یادگیری ($\eta$)

کوچک: کند، بزرگ: نوسانی یا واگرا

📉 انواع

Batch، Stochastic (SGD)، Mini-batch

🎲 Logistic Regression

خروجی پیوسته را به احتمال تبدیل می‌کند — برای طبقه‌بندی.

$$\sigma(z) = \frac{1}{1 + e^{-z}}, \quad z = \mathbf{w}^T\mathbf{x} + b$$ تابع Sigmoid — خروجی بین ۰ و ۱

🎯 طبقه‌بندی

اگر $\sigma(z) > 0.5$ → کلاس ۱، وگرنه کلاس ۰

📐 تابع هزینه

⚠️ Overfitting و Underfitting

Underfitting

مدل خیلی ساده — حتی روی داده آموزشی هم خطای بالا دارد.

راه‌حل: مدل پیچیده‌تر، ویژگی بیشتر

Good Fit

مدل بهینه — روی داده آموزش و تست خوب عمل می‌کند.

Overfitting

مدل خیلی پیچیده — داده آموزش را حفظ کرده ولی روی داده جدید ضعیف است.

راه‌حل: Regularization، Dropout، داده بیشتر

🛡️ Regularization

جریمه‌کردن پارامترهای بزرگ برای ساده‌تر نگه‌داشتن مدل.

$$L_{Ridge} = MSE + \lambda \sum w_i^2$$Ridge Regression (L2)
$$L_{Lasso} = MSE + \lambda \sum |w_i|$$Lasso Regression (L1) — پارامترهای بی‌اهمیت را صفر می‌کند

λ = 0

💻 پیاده‌سازی — MATLAB و Python

% رگرسیون خطی ساده با داده فرضی
x = (1:20)';
y = 2*x + 3 + 0.5*randn(20,1);

% Normal Equation
X = [ones(20,1), x];
w = (X' * X) \ (X' * y);

% نمایش
fprintf('w0 = %.2f, w1 = %.2f\n', w(1), w(2));
plot(x, y, 'bo'); hold on;
plot(x, X*w, 'r-');
legend('داده', 'خط برازش');
import numpy as np
import matplotlib.pyplot as plt
from sklearn.linear_model import LinearRegression

np.random.seed(42)
x = np.arange(1, 21).reshape(-1, 1)
y = 2*x.ravel() + 3 + np.random.randn(20)*0.5

model = LinearRegression()
model.fit(x, y)

print(f"w = {model.coef_[0]:.2f}")
print(f"b = {model.intercept_:.2f}")
print(f"R² = {model.score(x, y):.4f}")

plt.scatter(x, y, color='blue')
plt.plot(x, model.predict(x), 'r-')
plt.show()
