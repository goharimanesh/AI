Project Lifecycle

چرخه عمر پروژه هوش مصنوعی

یک پروژه موفق مهندسی مکانیک فقط کدنویسی نیست؛ یک چرخه ۶ مرحله‌ای است.

۱. داده (Data)

جمع‌آوری، پاکسازی و پیش‌پردازش داده‌های حسگرها، آزمایشات و شبیه‌سازی‌های FEM.

۲. مدل (Model)

انتخاب معماری مناسب (MLP، CNN، PINN، یا الگوریتم‌های RL) بر اساس فیزیک مسئله.

۳. آموزش (Train)

تنظیم هایپرپارامترها، تعریف تابع خطا و استفاده از شتاب‌دهنده‌ها (GPU در Colab).

۴. ارزیابی (Evaluate)

تست مدل با داده‌های ندیده، بررسی Overfitting و مقایسه با معیارهای فیزیکی.

۵. گزارش (Report)

مستندسازی کدها، ترسیم نمودارها و نگارش یافته‌ها طبق استانداردهای علمی.

۶. ارائه (Present)

دفاع از پروژه، توضیح محدودیت‌ها و پیشنهاد کارهای آینده.

Data Insights

نگاه موشکافانه به داده‌ها

قبل از هر مدل‌سازی، باید بدانید داده‌ها چه می‌گویند. داده‌های مکانیکی همیشه نویز دارند.

چالش‌های داده در مکانیک

  • نویز سنسور: سیگنال‌های ارتعاشی همیشه دارای نویز فرکانس بالا هستند.
  • داده‌های پرت (Outliers): خرابی ناگهانی یا خطای اندازه‌گیری.
  • عدم تعادل داده (Imbalance): در تشخیص خرابی، داده‌های سالم بسیار بیشتر از داده‌های معیوب هستند.

pytorch_model.py
import torch
import torch.nn as nn
import torch.optim as optim

# 1. Define a simple MLP for regression
class MechNet(nn.Module):
    def __init__(self):
        super(MechNet, self).__init__()
        self.layers = nn.Sequential(
            nn.Linear(3, 64),  # Input: 3 features (e.g., force, temp, speed)
            nn.ReLU(),
            nn.Linear(64, 32),
            nn.ReLU(),
            nn.Linear(32, 1)   # Output: 1 target (e.g., displacement)
        )
    
    def forward(self, x):
        return self.layers(x)

# 2. Setup Data (Dummy data)
X_train = torch.randn(100, 3)
y_train = torch.randn(100, 1)

# 3. Initialize Model, Loss, Optimizer
model = MechNet()
criterion = nn.MSELoss()
optimizer = optim.Adam(model.parameters(), lr=0.01)

# 4. Training Loop
for epoch in range(100):
    optimizer.zero_grad()
    outputs = model(X_train)
    loss = criterion(outputs, y_train)
    loss.backward()
    optimizer.step()
    
    if (epoch+1) % 10 == 0:
        print(f'Epoch [{epoch+1}/100], Loss: {loss.item():.4f}')

print("Training Complete!")
